# UMCP Implementation Plan

> **For agentic workers:** execute the independent components in their assigned file scopes; the coordinator integrates and verifies the complete MCP.

**Goal:** Local MCP for browser navigation, game UI observation, adjustable visual fallback and filtered HTTP/WS exports, verified in GitHub Actions.

**Architecture:** One stdio MCP process controls isolated Playwright contexts. UI, imaging and network modules have independent contracts and are exercised through the same browser service used by tools.

**Tech Stack:** Node >=22, JavaScript ESM, Playwright, official MCP SDK, sharp, node:test.

**Spec:** `docs/superpowers/specs/2026-10-26-umcp-design.md`.

## Global Constraints

- Local execution only; no Cloudflare deployment.
- Original HARs and live credentials must never be committed.
- Coordinates are CSS pixels in the main viewport, with explicit image transforms.
- Detection must disclose inaccessible canvas semantics and dropped/truncated capture data.
- No autonomous clicking; observation/stability is requested by the caller.

## Review Focus

- Screenshot downsizing/cropping must not move the eventual click.
- Iframe offsets, nested frames and shadow roots must preserve top viewport coordinates.
- Navigations, page switching and changed controls must invalidate stale references.
- Export filters/redaction must apply equally to query URLs, HTTP bodies and WS frames.
- Session close and capture limits must not silently lose in-flight data.

## Task 1: Network and HAR

Files: `src/network.js`, `test/network.test.js`.

Interfaces: export `NetworkRecorder`, `filterHar`, `summarizeHar`, `detectFamily`. Constructor options `maxEntries=10000`, `maxBodyBytes=262144`, `maxWebSocketFrames=10000`, `captureBodies='activity'`. Methods `attach(context)`, `flush()`, `query(options)`, `detail(id, options)`, `endpoints(options)`, `exportHar(options)`, `mark(label)`, `stats()`, `dispose()`. Filters: `preset` full/activity/metadata/ws, `urlIncludes`, `domains`, `methods`, `resourceTypes`, `statusMin/statusMax`, `since/until` epoch ms, `limit/offset`, `includeBodies`, `redact=true`, `transport` all/http/ws. Detail and export preserve binary as base64; metadata names truncation and eviction.

- [ ] Write failing behavior tests for filtering/redaction, HAR WS extensions and limits.
- [ ] Implement capture and pure filtering with bounded entries/bodies/frames.
- [ ] Run tests and report commands/results.

## Task 2: UI observation

Files: `src/ui.js`, `test/ui.test.js`.

Interfaces: `installInstrumentation(context)` before any navigation; `detectUI(page, {maxControls=200})` returns `{controls, canvases, engines, frames, needsVision, warnings}`. Controls `{id,source,kind,label,x,y,width,height,center:{x,y},normalized:{x,y},frameUrl,frameIndex,selector?,confidence}`; source dom/engine/canvas-text/manual. `observeStable(page, {samples=3,intervalMs=2000,tolerancePx=3,maxControls})` returns detection plus `stable`, sample count and timing. `validateControl(page, control, {tolerancePx=3})` confirms target remains visible in same position. IDs deterministic within document. `installInstrumentation` returns no page content.

- [ ] Write tests for DOM, hidden/occluded controls, iframe offsets, normalized coordinates, unstable controls and canvas fallback.
- [ ] Implement bounded read-only observation and optional engine discovery.
- [ ] Run tests and disclose exact coverage limitations.
